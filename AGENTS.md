# Project memory: CAP-steroids

## Environment (this Mac)

- Analysis and site are run in Positron on this Mac. **Pinned Quarto: 1.9.35** (`/Applications/quarto/bin/quarto`, also linked at `/usr/local/bin/quarto`). Check `quarto --version` before any render.
- The committed `docs/` was last generated by Quarto 1.11.9 (the 10 Nov run on another machine). The first render here with 1.9.35 will change the HTML of every page: commit the regenerated `docs/` separately from the source.
- R 4.5.1 and CmdStan 2.40.0 on this Mac; `analysis/renv.lock` records R 4.5.1. Work inside `analysis/` (its `.Rprofile` activates renv). Reruns differ from committed outputs by Monte Carlo noise: compare with a tolerance and revert output files that changed only by noise.
- `tar_make()` includes a `site` target (`tar_quarto`) that renders into `docs/`. To rebuild results without rendering, use `tar_make(names = !site)`.
- A rerun from the current `_targets` store refits nothing; only the cheap figure and table file targets rebuild (seconds) after `analysis/output/` files are reverted. `sim_outputs` (about 2 min) has `tar_cue(file = FALSE)`, so reverting its CSVs does not rerun it; delete them to force a rerun.
- Outside RStudio, set `RSTUDIO_PANDOC` before `tar_make()` so the PRISMA figure can be saved.
