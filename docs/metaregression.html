Each regression fits \(\theta_k = \mu + b\,x_k + u_k\) with covariates centred (continuous ones also scaled to SD 1, so \(b\) is per SD; for binary covariates \(b\) is the difference between groups). A covariate is fitted only if at least four trials have data and it varies. These are across-trial, ecological analyses with very few trials; they are underpowered and not confirmatory.

Code 
mr_fit <- filter(mr, status == "fitted")
n_excl0 <- sum(mr_fit$b_q025 > 0 | mr_fit$b_q975 < 0)

22 regressions were fitted and 1 has a 95% credible interval that excludes zero. With this many regressions, about one interval in twenty would be expected to exclude zero by chance, so none of these results should be read as confirmatory.

Coefficients with a probability of a negative sign of at least 0.90 or at most 0.10 (the most directional results): Prednisone-equivalent dose (mg/day) in F1 (b = -1.17, P(b<0) = 0.99); Double-blind placebo (1 = yes) in F1 (b = -0.72, P(b<0) = 0.91); Treatment duration (days) in F4 (b = 0.17, P(b<0) = 0.08). All other coefficients are centred close to zero with wide intervals, so these regressions do not identify a covariate that explains differences between trials. Several have very few trials in one group (for example only one trial coded 1 for the mineralocorticoid covariate), which limits what can be learned.

pred <- mr |> filter(set == "F1", covariate == "prednisone_equiv_mg_day", status == "fitted")

The F1 prednisone-equivalent dose regression (5 trials with data; Marik and Torres have weight-based regimens and drop out) gives b = -1.17 (-2.42 to -0.16) per SD, with an SD of only 4.5 mg/day: the five trials lie between 50 and 60 mg/day and one trial (Confalonieri) is the only one above 50, so this coefficient should not be read as a dose-response estimate.
